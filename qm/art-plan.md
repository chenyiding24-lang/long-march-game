## 1. 视觉审计

### 1.1 地图 SVG 绘画质量
- **现状**：纯 SVG 矢量「路线示意图」（`game.js` 注释 + `index.html` footer 声明「地图为路线示意图，省界非精确边界」）。含省界文字、江河描边、山脉 glyph、地形 `url(#hatch)`/`url(#marsh)` 填充、虚线路线、节点（圆+标签+stroke halo）。
- **评价**：定位准确，不应追求写实；质量抓手在 (a) 地形纹理一致性、(b) 缩放可读、(c) 与 CG 的色系统一。当前 hatch/marsh 纹理与 vignette 已给出基本质感，无需大改。
- **建议**：保留示意风；如需提质，优先强化 hatch/marsh 纹理密度与节点标签可读性（现有 `n-label` 的 `paint-order:stroke` halo 已够用）。

### 1.2 配色体系一致性
- **发现**：`art/README.txt:11` 定义美术色调 **土红 `#8C3B2E`** / 暖灰 `#B8AC93` / 暗部冷蓝 `#4A5A63` / 纸白 `#E6DCC4`；但 `style.css:11-12` 实际 `--red:#a8342a`、`--red-2:#b5382b`（更偏绯红）。CG 按 `#8C3B2E` 家族出图，UI 按 `#a8342a` 渲染 → 红系轻微割裂。
- **建议（可选，风险中）**：将 `--red/--red-2` 对齐到文档土红 `#8C3B2E`（暗部用 `#7a3326`），或反过来把文档改成实际值，二选一统一一源。改动波及全站，须主理人审批 + 回归。

### 1.3 CG 放映机（Ken Burns / 天气粒子 / no-art 降级）
- **现状**：`game.js:175-228` `CgWeather`（canvas 粒子，上限 60，掉帧自关，`prefers-reduced-motion` 不启动）；`Router`（`game.js:234-269`）构建 `.cg-stage`；图缺失/失败 → `.no-art` 隐藏，仅留文字 CG（已验证 0/21 降级生效）。Ken Burns 8–14s（`style.css:459-471`），底部 scrim 压暗 78%（`style.css:448`）。
- **评价**：降级健壮、体验闭环；`reduced-motion` 下运镜/粒子/文字淡入正确关闭（`style.css:473-477`）。
- **缺口（低）**：`cg-img` 仅 `alt=""`，建议补 `aria-hidden="true"`（装饰层，避免读屏多念）。

### 1.4 移动端三档布局
- **760px**（`style.css:580-638`）：顶栏换行 + 导航横滚；HUD 转底栏 `bottom:92px`；托盘横滚；弹窗近全屏；控件 ≥40px。
- **430px**（`style.css:639-646`）：再缩字号。
- **hover:none**（`style.css:648-651`）：去悬停态。
- **评价**：三档齐全，触控目标基本 ≥40–44px（`.chip` `.map-tools` `.opt` `.btn` `.next-arrow`）。
- **缺口（低）**：竖屏矮高度时 HUD(92)+托盘+控件(150) 可能挤压地图可视区；380/360 档继承 430 即可，未单独处理。发布前建议用真机窄高屏过一遍。

### 1.5 UI 视觉一致性

## 2. 无障碍审计（问题清单 + 修复规格）

> 对比度比值为按 sRGB 相对亮度估算（≈），落地前建议用 axe / 对比度校验器复测。所有 CSS/JS 落地由主理人 gate。

### 严重（阻断键盘可达）
- **A1 · Tab 被全局劫持**：`game.js:1015-1016` `if (e.key === 'Tab') { e.preventDefault(); this.setFar(!this.far); }` —— 主地图界面 Tab 完全失效，导航/按钮/托盘均无法键盘聚焦，破坏焦点顺序（且违反「Tab 不应被夺走」的基本原则）。
  **修复规格**：删除该 `Tab` 分支；远望全图改用 `'f'` 键（`Far` 含义直观）或既有 `#far-toggle` 按钮；保留 `+/-` 缩放与 `Space` 走下一站。让 Tab 原生遍历 `#topnav` / `#next-pill` / 托盘 / 地图工具。
- **A2 · SVG 节点不可键盘选择**：`game.js:1008-1013` 仅在 `#node-layer` 委托 click，节点无 `tabindex`/`role`/`Enter` 处理。键盘用户只能靠 `Space` 走「下一站」，**无法选择分支**。
  **修复规格（代码，主理人 gate）**：对 `.reach`/`.next` 节点加 `tabindex="0" role="button" aria-label="行军至 <地名>"`；在现有 keydown 监听增补 `Enter`/`Space` → `Game.onNodeClick(dataset.node)`（注意与 Space 走下一站互斥：聚焦在节点时 Space 选节点，聚焦在按钮时让给按钮）。
- **A3 · 弹窗缺焦点管理**：`game.js:233-314` 打开时未把焦点移入 `dialog`，关闭未还原到触发元素；无焦点陷阱（Tab 可跑出 dialog 到背景 `#viewport`）；`aria-label` 标题可升级为 `aria-labelledby` 指向 `<h2>`。
  **修复规格（代码）**：打开时 `dialog.focus()`（或首个 `.btn`/`modal-x`），并设 `tabindex="-1"` 于 `.modal`；捕获 Tab 在 dialog 内循环；关闭时 `prevFocus.focus()`；将 `aria-label` 改为 `aria-labelledby="<h2 id>"`。

### 中（对比度 AA 不达标，浅底正文/小字需 ≥4.5:1）
- **A4 · 浅底小字灰阶不足**（modal 亮底 ≈ `#efe7d2`，L≈0.76）：
  - `.src` `#8b8271`（≈3.1:1，`style.css:359`）
  - `.brief` `#7b7261`（≈3.9:1，`style.css:356`）
  - `.dim` `#8b8271`（≈3.1:1，`style.css:358`）
  **修复**：统一到 `--ink-3:#5c5346`（已用于 `.echo`，`style.css:667`，≈6:1）。改三处颜色即可，零风险。
- **A5 · 深底小字不足**（深底 ≈ `#14120f`，L≈0.01）：
  - `.footbar` `#6b6458`（≈2.96:1，`style.css:570`）
  - `.brand-sub` `#857c6c`（≈3.9:1，`style.css:51`）
  - `.map-note` `#7f7768`（≈3.0:1，`style.css:272`）
  - `.compass em` `#6f675a`（≈3.1:1，`style.css:277`）
  **修复**：提到 `#9a9282` 一带（≈5.6:1）。改四处方可。
- **A6 · 资源 low/zero 仅颜色区分**：`.res.low`/`.res.zero`（`style.css:103-105`）仅靠改色 + 闪烁传达状态，色盲/低视力难辨。
  **修复**：加非颜色线索（如「低/缺」文字徽标或图标），并给 `aria` 语义（如 `aria-label` 含「兵员 紧缺」）。

### 低（动效 / 跳转 / 缩放）
- **A7 · `prefers-reduced-motion` 覆盖不全**：仅 CG 动效被关（`style.css:473-477`）。地图装饰循环未关：`.route.now` march-line、`.node.reach .hit` breathe、`.node.next` halo/ring spin、`.army-pulse`、`.next-pill .np-go` nudge、`#next-arrow` beat、`.res.zero` blink、`.float` rise。
  **修复**：在同媒体查询内追加这些选择器的 `animation:none`（保留静态高亮，如红圈常显不转）。
- **A8 · 缺 skip-link**：顶栏导航按钮多，键盘用户绕行成本高。**修复**：加 `<a class="skip" href="#viewport">跳到地图</a>`，offscreen→`:focus` 显示（CSS `position:absolute;left:-9999px` + `:focus{left:8px}`）。
- **A9 · 200% 文本缩放未系统验证**：modal 有 `max-height+overflow` 应可；地图用 transform 缩放。建议发布前用 200% zoom 跑一遍自检 + 手测。
- **A10 · CG 装饰层缺 `aria-hidden`**：`cg-img` 补 `aria-hidden="true"`（低风险）。
