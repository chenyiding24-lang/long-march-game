# 《长征：万水千山》植被与山体写实规范

> 目标：回答用户「山为什么光秃秃、现实中山是不是这样」的疑问，并给出可落地的程序化植被/山体规则。
> 本文只做美术与写实判定，不改动任何代码。所有结论基于 `route3d.html` 真实结构核对（见附录）。

---

## 0. 先回答用户的两个疑问

1. **「现实中的山是光秃秃的吗？」——要看是哪一段。**
   - **陕北黄土高原（吴起镇）确实是秃的、且就该是秃的**：千沟万壑的黄土、植被稀疏，这是历史上真实地貌（1930 年代更甚）。这一段「秃」是**写实**，不要强行加绿（见第六节）。
   - **其余六段（赣/湘/黔/川/甘/草地）本该有显著植被**，现在看着全秃，是**渲染 bug**，不是现实。
2. **「bug 在哪？」** —— 当前植被生成被 `if (cell <= 5.2)` 门控，而 `LOD_CELL` 为 `[3.2, 6.4, 12.8]`（低画质 `[4.8, 9.6, 19.2]`）。**只有最贴近相机的一圈（3.2/4.8 格距）才种树**，中远距离（6.4/9.6/12.8/19.2）一律不生成任何树、草、石。于是整张图在通常视角下「全是光秃秃的同一张皮」。修复方向：把植被下放到中档 LOD（用更稀疏、更简化的形态），而非只在最近圈种。

## 一、逐地域写实判定（按长征路径顺序）

代码真实地域 key（供工程对齐）：`gan` 赣南·粤北丘陵 / `xiang` 湘桂走廊 / `qian` 黔北·川南 / `chuan` 川西高原 / `grass` 若尔盖草地 / `min` 甘南·岷陇 / `shaan` 陕北·黄土高原。

| 地域 key | 历史该长什么 | 该绿 / 该秃 / 该灰岩 | 当前判定是否写实 |
|---|---|---|---|
| `gan` 赣南·粤北 | 亚热带**常绿阔叶林**+竹林+红壤果园 | **该绿**（常绿阔叶为主） | 不写实（被 LOD 门控吃掉） |
| `xiang` 湘桂走廊 | 亚热带**针阔混交林**，江岸垂柳 | **该绿**（阔叶+河柳） | 不写实 |
| `qian` 黔北·川南 | **喀斯特**峰林：谷地常绿阔叶，陡崖**灰岩**裸露、崖脚灌丛藤蔓 | **该绿 + 该灰岩**（陡处露石灰岩，缓处绿） | 半写实（灰岩靠陡坡岩层理，但绿被吃掉） |
| `chuan` 川西高原（夹金山） | **暗针叶林**（冷杉/云杉）+ 高山草甸 + **雪** | **该绿（针叶）+ 该灰岩（高海拔裸岩）+ 该雪** | 雪带写实，林带被吃掉 |
| `grass` 若尔盖草地 | 高寒**湿地草甸/沼泽**（几乎无树） | **该绿（草甸，非裸土）**；「无树」是写实的 | 半写实（无树对，但应呈绿草甸而非枯黄裸地） |
| `min` 甘南·岷陇（腊子口） | 针叶林 + 峡谷裸岩 + 极高峰残雪 | **该绿 + 该灰岩 + 少量雪** | 不写实 |
| `shaan` 陕北黄土 | 黄土沟壑、稀疏灌丛/梯田，**严重缺林** | **该秃（黄土）**，点缀稀疏灌丛 | **写实**（但缺沟壑与稀疏灌丛，显得「只是丑秃」而非「真黄土」） |

> 结论：**七段里只有 `shaan` 与 `grass` 的部分「秃」是写实的；其余五段现在秃，是 bug**。

## 二、海拔分带与雪线（基于实测高程 4.7–98.2）

用「绝对高程 y（世界单位）」结合坡度 `slope` 判定。代码已有相对分带公式（`treeLine = alt + relief*0.48`，`alpine = alt + relief*0.80`），下表给出可直接用的**绝对阈值参考**与雪线定位：

| 分带 | 绝对 y 区间（参考） | 坡面表现 | 程序化判定（y 与 slope） |
|---|---|---|---|
| 河谷/低地湿地 | y < 15 | 草甸、芦苇、河岸灌丛 | `y<15 && slope<.6` → 草/苇；近水优先 |
| 森林带（林线以下） | 15 – 50（地域林线见下） | 按地域常绿/针叶/阔叶 | `y<treeLine && slope<.55` → 树 |
| 灌丛/高山草甸带 | 林线 – 灌丛线 | 矮灌、草甸斑 | `treeLine<y<alpine && slope<.72` → 灌丛/草甸色 |
| 裸岩碎石带 | 灌丛线 – 雪线 | 灰岩、碎石、无植被 | `y>alpine && slope>.55` 或 `y>alpine && slope<.78` → 岩/石 |
| **雪线以上** | 见雪线列 | 积雪（偏冷暗白） | `y>snowLine && slope<.78` → 雪 |

**雪线定位（实测雪只出现在高山区）：**
- `chuan`：雪线约 **y>50**（半山腰以上即雪，夹金山实景）。
- `min`：雪线约 **y>96**（仅最极高峰顶残留雪，罕见）。
- 其余五段 `BIOME.snow = 999`，**不该积雪**（不要给赣湘黔黄土加雪）。

> 注意冲突处理：`chuan` 的 `snowLine(50)` 低于其 `alpine(≈74.6)`，故 50–58 区间同时受草甸与雪染色，按代码优先级雪覆盖即可——保持「雪在林线之上」的真实观感。

## 三、配色与「不丑」的平衡（写实 vs 好看）

核心原则：**分地域、分海拔给色，避免大块纯色死板**。

- **南方林段（gan/xiang/qian）**：基色用偏冷的**深绿**（代码 `lo≈[.24,.39,.20]`、`hi≈[.41,.53,.28]`），靠 `voxColor` 里的大尺度明暗 `lum`（±.28）与抖动 `jit` 打碎均匀感；暖光斑由 `WEATHER` 的暖色夕照（xiang 血色天光、qian 冷雨灰）自然产生，**不要整体加亮**。
- **喀斯特段（qian）**：陡坡露**石灰岩灰**（`rock≈[.49,.37,.30]`）是对的，但缓谷要回填绿；灰岩与绿的交界靠 `slope` 阈值自然过渡，避免一刀切。
- **黄土段（shaan）**：基色暖黄褐（`lo≈[.58,.48,.28]`、`hi≈[.74,.62,.36]`），**靠沟壑阴影与梯田明暗制造体积**，绝不用绿色救「丑」——秃且暖黄、有沟壑，才是好看的黄土。
- **雪段（chuan/min）**：雪用**冷灰蓝白**（`[.72,.78,.83]`），叠雪裂隙冷蓝凹陷（`cr` 噪声），避免纯白过曝。

## 四、可程序化规则清单（给 engineering-lead 直接落地）

约束：**零外链、纯顶点色/程序化，禁止贴图与 CDN**；所有形态用现有 `vhtree` / `vhbox` 体素。

1. **解除 LOD 门控**：把植被生成从 `cell <= 5.2` 扩展到中档（如 `cell <= 12.8`），中远距离用**低密度 + 简化形态**（矮灌丛/贴地草色斑/扁石），最近圈保持现有林团密植。
2. **每地域密度系数 `dens`（相对当前 high=0.0096）**：
   - `gan/xiang/qian`：1.0（最密，常绿阔叶）
   - `chuan/min`：0.8（针叶，近林线矮化）
   - `grass`：0.15（仅草甸/苇，无树）
   - `shaan`：0.25（稀疏灌丛/梯田，不密）
3. **最低坡度/海拔门槛**（沿用并强化）：树 `slope<.50`；草/灌 `slope<.62`；碎石 `slope<.42` 缓坡卧石、`slope>.62` 岩坡孤石；`waterAt` 一律不种；`y>b.snow-8` 不种树。
4. **颜色区间**（直接复用 `BIOME[rk].lo/hi/rock`，不要硬编码新色）：树冠在 `hi` 附近 ±.06 抖动；石用 `b.rock*（.85~1.05）`；草簇 `[.30,.40,.22]±.1`。
5. **与现有生成点衔接**：保留「2–4 林团聚簇 + 高斯散布」逻辑；`grass` 段强制 `marshgrass`；`qian` 陡坡处抑制树、改露岩（已部分实现，需确保 `karst` 参数驱动露岩概率）。
6. **黄土段特殊处理**：用 `STRATA.gully` 实现沟壑侵蚀下切 + 梯田台地（`terr:.90` 已高），稀疏 `shrub/tea`，**不引入 pine 大面积绿**。

## 五、明确标注：哪些「秃」是写实的（不要强行加绿）

- ✅ **`shaan` 陕北黄土**：全段该秃（暖黄沟壑），只补稀疏灌丛/梯田，禁止大片绿。
- ✅ **`grass` 若尔盖**：无树是写实，但须呈**绿草甸/沼泽色**，不是枯黄裸土。
- ✅ **`chuan`/`min` 雪线以上（y>50 / y>96）**：该秃且覆雪/裸岩，写实。
- ❌ **`gan`/`xiang`/`qian` 缓坡林带、`chuan`/`min` 林线以下**：现在秃是 **LOD bug**，必须补绿。

## 附录：代码真实结构核对（grounding 事实）

- **STRATA（7 段，t=0 陕北→t=1 赣南）**：`shaan`(t.050,alt26,relief15,gully5) / `min`(t.130,alt24,relief42,snow96) / `grass`(t.220,alt29,relief5) / `chuan`(t.385,alt33,relief52,snow56) / `qian`(t.650,alt16,relief30,karst6) / `xiang`(t.835,alt7,relief24) / `gan`(t.925,alt4,relief13)。
- **BIOME 色（lo/hi/rock/snow）**：见第一节表格对应；雪线 `chuan=56`、`min=96`、其余 `999`。
- **voxColor 着色链**：`mix(lo,hi,k)` → 枯黄草甸斑(h>alt+12,slope<.35) → 林线以上草甸(h>treeLine,slope<.72) → 灌丛线以上灰裸岩(h>alpine,slope<.82) → 雪线以上雪(h>snowLine,slope<.78) → 陡坡岩层理(rw=(slope-.72)/.85) → 湿河床 → 大尺度明暗。
- **植被生成点**：`buildVoxelChunk` 内①树（林团聚簇，`cell<=5.2` 门控，按 region 选 `broadleaf/poplar/orchard/willow/fir/pine/shrub/tea/marshgrass/bush`）；②散落岩块（cnt*1.5，灰石）；③high 专属点缀（草簇/碎石/芦苇/孤石）。
- **高程**：实测 y≈4.7–98.2；`snowLineAt(t)` 在 t∈[.255,.50] 返回 50，其余 999。
- **LOD**：`LOD_CELL_HI=[3.2,6.4,12.8]`、`LOD_CELL_LO=[4.8,9.6,19.2]`；植被仅 `cell<=5.2` 触发 → **中远距无植被，这是「全图秃」根因**。
