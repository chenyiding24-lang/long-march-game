《长征：万水千山》CG 分镜图位
================================

这一目录放程序生成的分镜静帧。图由人来生成，代码已经全部接好：
只要把下面命名的文件放进本目录，对应的 cinematic 弹窗就会自动显示；
文件不存在或加载失败时，放映机会自动隐藏图，只留原来的文字 CG，游戏照常可玩。

【命名】cg-01.webp … cg-21.webp（两位数字，不加前导零以外的字符）
【尺寸】场景 1792×1024（16:9）；cg-16 木牌特写 1024×1536（2:3）
【格式】WebP，单张 ≤ 200KB，21 张合计 ≤ 3MB
【色调】土红 #8C3B2E / 暖灰 #B8AC93 / 暗部冷蓝 #4A5A63 / 纸白 #E6DCC4
【留白】所有横图下方三分之一保持干净，字幕要叠在那里

【提示词】18-CG生成提示词-可直接复制.md
  每张的中文提示词都是「风格前缀 + 画面 + 负面词 + 参数」拼好的完整块，
  整段复制进即梦 / 可灵 / 通义万相即可，不用自己拼。
  建议先出试片 5 张定风格：cg-01（于都河）、cg-09（泸定桥）、
  cg-10（夹金山）、cg-14（哈达铺）、cg-16（木牌特写）。

【运镜与天气】由 游戏/data.js 末尾的 CG_ART 表指定，调用点只写 art 编号。
  motion：pan-left / pan-right / pan-up / zoom-in
  weather：snow / rain / mist / ember / dust / spray / none（纯 canvas 粒子，零依赖）

【合规】出图后逐张人工核对旗帜与帽徽；不出现领袖肖像、党徽国徽、
  可辨认文字、血腥、现代物件。画不准的旗帜宁可只留一角或剪影。
  详见 18 号文档 §八。

  双击 index.html 可以完整试玩。出图是 T2 里唯一留给人的部分。
